## Quick Start

```bash
# Clone
git clone https://github.com/Krishpzs7/flowforge.git
cd flowforge

# Install dependencies (after setup)
npm install

# Run dev (after setup)
npm run dev
```

## Tech Stack

- **Frontend:** Next.js, TypeScript, React Flow, Tailwind CSS, shadcn/ui, Zustand
- **Backend:** Node.js, NestJS
- **Database:** PostgreSQL, Prisma
- **Queue:** BullMQ (Redis)
- **Infra:** Docker, GitHub Actions, AWS
